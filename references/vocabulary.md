### Self-Introduction Sentences
- *Mam na imię Ahmed.* — اسمي أحمد.
- *Jestem z Arabii.* — أنا من العربية.
- *Mieszkam w Polsce od X lat.* — أسكن في بولندا منذ X سنوات.
- *Pracuję jako analityk.* — أعمل كمحلل.
- *Uczę się polskiego.* — أتعلم البولندية.

## SECTION 11 — Connectors & Discourse Markers

| Polish | Arabic | Example |
|--------|--------|---------|
| i / oraz | و / وأيضاً | Kawa i herbata. |
| ale | لكن | Chcę, ale nie mogę. |
| bo / ponieważ | لأن | Jest zmęczony, bo dużo pracował. |
| więc | إذن / لذلك | Jest późno, więc idę spać. |
| też / również | أيضاً | Ja też lubię kawę. |
| albo / lub | أو | Herbata albo kawa? |
| jeśli | إذا | Jeśli chcesz... |
| że | أن / بأن | Myślę, że masz rację. |
| tylko | فقط | Tylko chwila. |
| może | ربما | Może jutro. |
| bardzo / trochę | جداً / قليلاً | Bardzo dziękuję. |
| już | الآن / قد | Już jestem. (أنا هنا الآن) |
| jeszcze | لا يزال / بعد | Jeszcze chwila. |
| Po pierwsze... | أولاً... | for lists in speaking |
