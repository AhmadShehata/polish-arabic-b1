# TELC Polski B1 — Exam Preparation Guide

## Exam Structure
| Component | Content | Time | Weight |
|-----------|---------|------|--------|
| Czytanie (Reading) | 3 texts + comprehension questions | 60 min | 25% |
| Słuchanie (Listening) | 3 recordings + questions | 30 min | 25% |
| Pisanie (Writing) | Letter ~150 words + form | 60 min | 25% |
| Mówienie (Speaking) | Monologue + role-play | 15 min | 25% |

**Pass mark:** 60% overall. No minimum per section in standard TELC B1.
**Source:** telc.net — download free practice tests there.

---

## READING — Czytanie

### Strategy
1. Read the questions FIRST (30 seconds)
2. Scan the text for answers — don't read word by word
3. Numbers, dates, proper nouns, and negations are always tested
4. Ignore unknown words; use context

### Text Types You'll See
| Type | What to look for |
|------|-----------------|
| Job advertisement (ogłoszenie o pracę) | Requirements, salary, hours, contact |
| Email/letter (e-mail/list) | Who sent it, what they want, what they offer |
| Short article (artykuł) | Main idea (usually in first sentence), examples |
| Announcement (ogłoszenie) | Times, places, prices, conditions |

## LISTENING — Słuchanie

### Strategy
1. Read the questions before the recording plays
2. The answer order usually follows the recording order
3. Listen for numbers, names, times — these are exactly what's tested
4. Second listening: confirm, don't second-guess first answers

### Recording Types
| Type | Listen for |
|------|-----------|
| Everyday dialogues (shop, doctor, station) | Who/what/where/when |
| Announcements (airport, station, shop) | Numbers, times, platform/gate |
| Short interview or monologue | Opinion, reason, conclusion |

### Phrases That Signal Key Information
| Polish | Significance |
|--------|-------------|
| Niestety... | Bad news coming — often tested |
| Chciałbym/Chciałabym... | Request being made |
| Proszę pamiętać, że... | Important reminder — likely tested |
| Zmiana! | Change of plan — tested |
| pociąg numer / lot numer | Number always tested |
| o godzinie... | Time always tested |

## WRITING — Pisanie

### Formal Letter Template (Szanowny Panie/Pani)

```
[City], [date in Polish: np. Wrocław, 9 kwietnia 2026]

Szanowny Panie / Szanowna Pani,

[Opening: state your purpose]
Piszę w związku z... / Zwracam się z prośbą o...
Piszę, ponieważ chciałbym / chciałabym...

[Body paragraph: details / explanation]
Chciałbym również dodać, że...
Niestety, mam problem z...
W związku z tym...

[Closing: request / next step]
Proszę o... / Czekam na odpowiedź.
Czy mógłby/mogłaby Pan/Pani...?

Z poważaniem,
[Name]
```

### Informal Letter Template (Drogi/Droga)

```
Drogi Ahmadzie / Droga Anno,

Mam nadzieję, że wszystko u Ciebie dobrze.
Piszę, bo chciałem / chciałam...

[Main message]
...

[Closing question or invitation]
Mam nadzieję, że wkrótce się zobaczymy.
Napisz do mnie wkrótce!

Pozdrawiam serdecznie,
[Name]
```

### Useful Writing Phrases by Function

| Function | Polish | Arabic |
|----------|--------|--------|
| Opening | Piszę w sprawie... | أكتب بشأن... |
| Opening | Zwracam się z prośbą o... | أتوجه بطلب... |
| Adding | Chciałbym również dodać, że... | أود أيضاً أن أضيف... |
| Opinion | Myślę, że... / Uważam, że... | أعتقد أن... |
| Problem | Niestety, mam problem z... | للأسف، لدي مشكلة في... |
| Request | Proszę o... | أرجو... |
| Request | Czy mógłby Pan / Pani...? | هل يمكنكم...؟ |
| Apology | Przepraszam za... | أعتذر عن... |
| Reason | Z powodu... nie mogłem/am... | بسبب... لم أستطع... |
| Closing | Czekam na odpowiedź. | أنتظر ردكم. |
| Closing formal | Z poważaniem, | مع التقدير، |
| Closing informal | Pozdrawiam serdecznie, | مع أطيب التحيات، |

### Common Exam Writing Tasks
Practice all of these before the exam:
- [ ] Complaint about hotel / restaurant / product
- [ ] Request for information about course / apartment / job
- [ ] Invitation to a friend for an event / visit
- [ ] Describing a trip or experience
- [ ] Responding to a job advertisement
- [ ] Apologising and explaining absence/delay

### Reported Speech — Essential for Writing Tasks
| Direct | Reported | Arabic |
|--------|----------|--------|
| "Jestem zmęczony." | Powiedział, że jest zmęczony. | قال أنه متعب. |

| "Nie rozumiem." | Zapytał, czy rozumie. | سأل إن كان يفهم. |

## SPEAKING — Mówienie

### Part 1: Monologue (3-4 minutes)

You receive a card with a topic and 3 bullet points.

**5-Step Monologue Structure:**
1. *Chciałbym opowiedzieć o...* — opener
2. *Po pierwsze...* — first point
3. *Po drugie... / Poza tym...* — second point
4. *Na koniec...* — third point
5. *Podsumowując, myślę, że...* — conclusion

**Practice Topics (all appear in TELC B1):**
- [ ] Moje ulubione miasto — أفضل مدينة عندي
- [ ] Moja praca lub studia — عملي أو دراستي
- [ ] Zdrowe życie — الحياة الصحية
- [ ] Podróże — السفر
- [ ] Technologia w życiu codziennym — التكنولوجيا في الحياة اليومية
- [ ] Ochrona środowiska — حماية البيئة
- [ ] Plany na przyszłość — خطط المستقبل
- [ ] Ważna osoba w moim życiu — شخص مهم في حياتي

### Part 2: Role-Play (5 minutes)

The examiner plays a character, you play a role. Common scenarios:

| Scenario | Key phrases needed |
|----------|-------------------|
| At the doctor (u lekarza) | Boli mnie..., Mam gorączkę, Proszę o receptę |
| At the restaurant (w restauracji) | Stolik dla..., Proszę kartę, Bez wieprzowiny |
| At the train station (na dworcu) | Proszę bilet do..., O której godzinie...? |
| In the shop (w sklepie) | Chciałbym zwrócić..., Czy mogę wymienić...? |
| Job interview (rozmowa kwalifikacyjna) | Mam doświadczenie w..., Jestem...em |

### Rescue Phrases — When You're Stuck
| Situation | Polish | Arabic |
|-----------|--------|--------|
| Didn't hear/understand | Przepraszam, czy mógłby Pan powtórzyć? | أعذرني، هل يمكنك الإعادة؟ |
| Need time to think | Chwileczk... / Dobrze, myślę, że... | لحظة... / حسناً، أعتقد أن... |
| Lost a word | To znaczy... / Chodzi mi o... | أعني... |
| Want to add something | A poza tym... / Chciałbym dodać... | وبالإضافة... |
| Asking for clarification | Czy dobrze rozumiem, że...? | هل أفهم صحيحاً أن...؟ |
| Disagreeing politely | Rozumiem, ale myślę, że... | أفهم، لكن أعتقد أن... |

### Examiner Expectations
The examiner wants to see:
- **Communication** over perfection — errors are fine, silence is not
- **Structure** — beginning, middle, end
- **Range** — use varied vocabulary and grammar
- **Interaction** — respond to what's said, not just what you prepared

## 4-WEEK SPRINT PLAN (Before the Exam)

### Week 1 — Reinforce Weak Points
- Day 1-2: Grammar cases — review error table in SKILL.md
- Day 3-4: Verb conjugation — test yourself on all 10 groups
- Day 5-7: Vocabulary — 20 words/day from exam topic sections

### Week 2 — Writing Practice
- Write one letter per day (formal alternating with informal)
- Use the templates above as scaffolding, then remove them
- Post to LangCorrect.com for native speaker correction

### Week 3 — Listening & Reading
- 15 min listening daily: Slow Polish podcast + transcript
- Read one short Polish text daily (online news, ogłoszenia)
- Practice the TELC B1 reading task format

### Week 4 — Mock Exam
- Day 1-2: Full TELC B1 mock exam (download from telc.net) under timed conditions
- Day 3-4: Review weak areas from mock results
- Day 5-6: Speaking practice — record yourself, listen back
- Day 7: Rest + review emergency phrases only

## Grammar Checklist Before Exam

Before writing or speaking, mentally check:
- [ ] Subject → Mianownik
- [ ] Direct object → Biernik (Dopełniacz after nie)
- [ ] Profession after być/zostać → Narzędnik
- [ ] słuchać / szukać / potrzebować → Dopełniacz
- [ ] pomagać → Celownik (komuś)
- [ ] po/w/na/o/przy → Miejscownik
- [ ] Adjective ending matches noun gender and case
- [ ] Past tense verb ending matches speaker's gender
- [ ] Perfective verb in "present" form = FUTURE meaning
- [ ] z (with people) → Narzędnik / do (direction) → Dopełniacz
